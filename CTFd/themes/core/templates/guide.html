01

WHAT IS CTF?

CTF(Capture The Flag)는 보안 문제를 해결하여 문제 속에 숨겨진 Flag를 찾는 방식의 보안 대회입니다.

UNKNOWN Beginner CTF에서는 여러 보안 분야의 입문 문제를 직접 해결하며 기본적인 보안 개념과 도구 사용법을 경험할 수 있습니다.

  1. CHALLENGE
  2. ANALYZE
  3. FIND FLAG
  4. SUBMIT
  5. GET POINTS
02

WHAT IS A FLAG?

Flag는 문제를 정상적으로 해결했다는 것을 증명하는 문자열입니다. Challenges의 제출 칸에 이 문자열을 입력하면 점수를 얻습니다.

UNKNOWN Beginner CTF의 Flag는 다음 형식을 사용합니다.

flag
$ flagUNKNOWN{example_flag}
KEEP IN MIND

대소문자, _ (underscore), 중괄호 { } 까지 정확히 입력해야 정답으로 인정됩니다. 앞뒤 공백도 주의하세요.

03

HOW TO PLAY

STEP 01

CHOOSE

Challenges에서 풀고 싶은 문제를 선택합니다.

STEP 02

ANALYZE

Description과 제공 파일을 확인하고 문제의 단서를 분석합니다.

STEP 03

CAPTURE

문제를 해결하여 UNKNOWN{...} 형태의 Flag를 찾습니다.

STEP 04

SUBMIT

Flag 입력창에 정답을 제출하여 점수를 획득합니다.

DIFFICULTY

문제마다 난이도가 표시됩니다. 낮은 단계부터 순서대로 풀면 자연스럽게 감을 잡을 수 있습니다.

LV 0TUTORIAL

CTF를 처음 시작하는 참가자를 위한 문제

LV 1BEGINNER

간단한 관찰이나 기본 도구로 해결 가능

LV 2INTRO

여러 단서를 연결하거나 간단한 분석 필요

LV 3CHALLENGE

조금 더 깊은 분석과 응용 필요

RECOMMENDED

처음이라면 낮은 Level과 100점 문제부터 시작해보세요.

06

STUCK?

막혔을 때 바로 정답을 찾지 말고, 아래 순서대로 시도해보세요. 막히는 구간이 실력이 늘어나는 구간입니다.

  1. Description을 다시 읽는다.
  2. 제공된 파일을 확인한다.
  3. 문제 이름을 다시 생각해본다.
  4. 모르는 용어나 파일 형식을 검색한다.
  5. Hint 1을 확인한다.
  6. Hint 2를 확인한다.
  7. Hint 3을 확인한다.
  8. 그래도 모르겠다면 운영진에게 질문한다.
ABOUT HINTS

Hint는 열기 전에 필요한 비용(점수)이 표시됩니다. 비용이 0인 Hint는 점수 차감 없이 볼 수 있습니다. 막혔을 때 Hint를 확인하는 것도 문제 풀이의 일부입니다.

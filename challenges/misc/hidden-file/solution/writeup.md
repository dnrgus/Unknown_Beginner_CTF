# MISC-01 Hidden File Writeup

## 문제 개요

압축 파일 안에 숨김 파일이 들어 있다.

## 핵심 개념

Linux/Unix 계열에서 `.`으로 시작하는 파일은 기본 `ls` 출력에 보이지 않는다.

## 분석

압축을 푼 뒤 `ls -la`로 전체 파일을 확인하면 `.flag.txt`를 찾을 수 있다.

## 풀이

Archive를 추출하고 숨김 파일을 확인한다.

## Flag 획득

`.flag.txt` 안의 `UNKNOWN{...}`를 제출한다.

## 학습 포인트

파일을 확인할 때 기본 출력만 믿지 말고 숨김 파일도 확인해야 한다.

# WEB-01 Source Hunter

- Category: Web
- Difficulty: Easy
- Description: A quiet page has a path hidden where browsers already know how to look. Find the hidden route and capture the flag.
- Files: Service only
- Connection: http://localhost:8101
- Flag Format: `UNKNOWN{example_flag}`

## Hints

1. The browser received more than just visible text.
2. Open page source or DevTools and look for an HTML comment.

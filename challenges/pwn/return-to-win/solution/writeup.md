# PWN-03 Return to Win Writeup

## 문제 개요

프로그램에는 `win()` 함수가 있지만 정상 흐름에서는 호출되지 않는다.

## 핵심 개념

ret2win은 스택 오버플로우로 저장된 반환 주소를 `win()` 함수 주소로 바꾸는 입문 기법이다.

## 분석

바이너리는 PIE 없이 빌드되어 함수 주소가 고정된다. `nm` 또는 `objdump`로 `win` 주소를 확인하고, 버퍼와 저장된 반환 주소 사이의 offset을 계산한다.

## 풀이

버퍼를 채운 뒤 저장된 RBP를 지나 `win()` 주소를 little-endian으로 넣는다. 이 바이너리에서는 64비트 스택 정렬 때문에 `win`의 첫 `push rbp`를 건너뛰는 `win+1` 주소를 사용한다.

## Flag 획득

반환 주소가 `win()`으로 바뀌면 함수가 실행되며 `UNKNOWN{...}` flag가 출력된다.

## 학습 포인트

반환 주소는 제어 흐름의 핵심 데이터다. 스택 오버플로우와 보호 기법의 관계를 이해하는 출발점이 된다.

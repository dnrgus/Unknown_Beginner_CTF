# PWN-01 Password Please Writeup

## 문제 개요

서비스는 비밀번호를 입력하면 맞는 경우 flag를 출력한다.

## 핵심 개념

초보 pwn의 첫 단계는 바이너리를 실행하기 전에 관찰하는 것이다. 평문 문자열은 `strings` 같은 도구로 확인할 수 있다.

## 분석

배포 파일에 대해 `strings`를 실행하면 비밀번호처럼 보이는 `open_sesame_2026` 문자열을 찾을 수 있다.

## 풀이

서비스에 접속해 해당 문자열을 비밀번호로 입력한다.

## Flag 획득

정답 비밀번호를 입력하면 `UNKNOWN{...}` 형식의 flag가 출력된다.

## 학습 포인트

바이너리 내부의 평문 문자열은 쉽게 노출된다. 중요한 비밀값을 바이너리에 그대로 넣으면 안 된다.

# Incident Log — UNKNOWN Beginner CTF

Copy the template below into a new entry each time something goes wrong
during setup or the live event. Keep entries in reverse-chronological order
(newest at top). Don't record secrets, passwords, or full participant PII
here — describe the problem, not sensitive data.

---

## Template

```
## [YYYY-MM-DD HH:MM] Short title

### Time
When it started / when it was noticed / when it was resolved.

### Problem
What happened, in plain terms. What you observed (error message, broken
page, participant reports, etc).

### Impact
Who/what was affected — all participants, one challenge, the scoreboard,
a specific account, etc. How long it lasted.

### Action
What you did to investigate and fix it. Commands run, settings changed,
services restarted.

### Result
Did it work? Confirm the fix from a participant's point of view, not just
"the container is running again."

### Follow-up
Anything to fix properly after the event, or to add to the pre-event
checklist next time so this doesn't happen again.
```
